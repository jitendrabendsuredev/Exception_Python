Part 1 — Basic Exception Handling

1. Employee Age Registration

ValueErrortry-except

HR software accepts employee age from the user. If the user enters text such as "twenty five", the system should not crash. Show a proper message.

Company Requirement: Application must continue gracefully even when invalid numeric input is entered.
Convert input using int() inside a try block and handle ValueError.
try:
    age = int(input("Enter employee age: "))
    print("Employee age:", age)

except ValueError:
    print("Invalid age. Please enter numbers only.")

2. Payroll Division Calculator

ZeroDivisionErrorValueError

A payroll team calculates salary per working day using salary / working_days. Handle invalid salary input and zero working days.

Use separate except blocks for ValueError and ZeroDivisionError.
try:

6. Banking Withdrawal Validation

raiseBusiness Rule

A banking system has balance ₹10,000. Withdrawal amount must be greater than zero and must not exceed balance.

Raise a ValueError for invalid withdrawal conditions.
balance = 10000

try:
    amount = float(input("Enter withdrawal amount: "))

    if amount <= 0:
        raise ValueError("Amount must be greater than zero")

    if amount > balance:
        raise ValueError("Insufficient balance")

    print("Withdrawal successful")

    print("Transaction failed:", e)

13. Custom InsufficientBalanceError

Custom Exception

Create a custom exception named InsufficientBalanceError. Raise it when withdrawal amount is greater than account balance.

Create a class that inherits from Exception.
class InsufficientBalanceError(Exception):
    pass

balance = 5000

try:
    amount = float(input("Enter withdrawal amount: "))

    print("Transaction successful")

20. Mini Project — Company Order Processing

Final Challenge raise Custom Exception else finally

Create a small company order system with the following rules:

  • Available stock = 100 units.
  • Product price = ₹500 per unit.
  • User enters quantity.
  • Quantity must be numeric and greater than zero.
  • If quantity exceeds stock, raise a custom StockError.
  • On successful order, calculate total bill and remaining stock.
  • Always print "Order request completed".
Use custom exception + ValueError + else + finally.
class StockError(Exception):
    pass

stock = 100
price = 500

try:
    qty = int(input("Enter order quantity: "))

    if qty <= 0:
        raise ValueError("Quantity must be greater than zero")

    if qty > stock:
        raise StockError("Requested stock is not available")

    total = qty * price
    stock -= qty

except ValueError as e:
    print("Invalid input:", e)

except StockError as e:
    print("Order rejected:", e)

else:
    print("Order confirmed")
    print("Total Bill:", total)
    print("Remaining Stock:", stock)

finally:
    print("Order request completed")
